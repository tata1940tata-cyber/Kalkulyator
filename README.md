## 📌 Название и суть

**«МАРКЕТ» (MarketCalc)** — локальное настольное приложение для продавцов на Яндекс Маркете. Загружаешь таблицу с товарами и тарифами — и видишь расходы, маржу и цену под целевую маржу по каждому SKU. Работает офлайн, в интернет не обращается, данные не покидают компьютер.

## 🎯 Решаемая задача

Продавец на Яндекс Маркете платит десятки комиссий: комиссия категории, логистика по объёму, последняя миля, эквайринг, хранение, возвраты, утилизация, штрафы, ДРР и налоги. Считать всё это вручную в Excel — значит ошибаться и продавать в минус, сам того не зная.

| Проблема продавца | Решение в приложении |
|---|---|
| «Не понимаю, сколько я реально зарабатываю» | Полная структура расходов по каждому товару |
| «Какую цену поставить, чтобы выйти на маржу 20%?» | Автоподбор цены под целевую маржинальность |
| «Акции съедают маржу?» | Расчёт по ценам входа в акции с флагами «убыток», «ниже минимальной цены» |
| «Тарифы меняются каждый сезон» | Версионирование тарифов: старые версии не переписываются |
| «Не хочу отдавать данные в облако» | Полностью локальная работа, без внешних сервисов |

## 👥 Кому это пользователь

- **Продавец / владелец бренда** — принимает решения о ценах и ассортимменте;
- **Менеджер по ассортименту** — планирует акции и скидки без ущерба для маржи;
- **Финансист / аналитик** — проверяет юнит-экономику портфеля перед закупкой.

### Сценарии использования

1. **Обзор портфеля.** Загрузил данные → видишь таблицу SKU: цена, расходы, маржа, маржинальность, статус.
2. **Карточка товара.** Открыл конкретный SKU → полная структура расходов и цена под цель.
3. **Проверка акции.** Указал цены входа → приложение показывает маржу по каждой акции и максимальную допустимую скидку.

## ✨ Возможности

- 📋 **Обзор** — портфель SKU: цена, расходы, маржа, маржинальность, цена под целевую маржу, статус.
- 🧮 **Калькулятор** — карточка товара с полной структурой расходов и расчётом цены под цель.
- 💸 **Тарифы** — комиссии по категориям, логистика по объёму, последняя миля, эквайринг, хранение, возвраты, утилизация, штрафы, налоги.
- 📥 **Загрузка данных** — книга Excel (`.xlsx`) или CSV: листы «Товары», «Комиссии», «Логистика», «Прочие тарифы», «Акции», «Настройки».
- 📄 **Готовый шаблон** — кнопка «Шаблон» скачивает книгу со всеми листами и примерами.
- 🚩 **Флаги контроля** — «убыток», «ниже минимальной цены», «ниже минимума маржи».
- 🖥 **Простая установка** — двойной клик по установщику, без прав администратора, ярлыки создаются автоматически.
- 🔒 **Офлайн-работа** — данные остаются на компьютере, приложение в интернет не обращается.

## 🚀 Быстрый старт

**Пользователю** — скачай релиз и дважды кликни `МАРКЕТ_Установка.exe`: установка проходит автоматически, приложение запускается само. Удаление — «Параметры → Приложения → МАРКЕТ».

**Разработчику:**

```bash
git clone https://github.com/tata1940tata-cyber/Kalkulyator.git
cd Kalkulyator/MarketCalc
pip install openpyxl
python app/server.py
```

Сервер поднимется на свободном порту и откроет интерфейс в окне Chrome (режим приложения).

**Сборка exe и установщика** (из `MarketCalc/`):

```bash
pip install openpyxl pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name MarketCalc ^
  --icon assets/icon.ico --add-data "app/web;web" --add-data "app/data;data" app/server.py
python -m PyInstaller --noconfirm --onefile --windowed --name MarketCalc_Setup ^
  --icon assets/icon.ico --add-data "dist/MarketCalc.exe;payload" ^
  --add-data "assets/icon.ico;assets" installer/setup.py
```

## 🧮 Методика расчёта

```
Маржа           = выручка − сумма расходов
Маржинальность  = маржа / выручка
Последняя миля  = min(макс, max(мин, цена × ставка))
Цена под цель   = бисекция по маржинальности + округление вверх + минимум цены
```

Полное описание формул, сущностей и контрольные примеры — в [docs/data_model.md](docs/data_model.md). Пакет входных данных и правила его расширения — в [docs/data-package.md](docs/data-package.md).
