# МАРКЕТ — калькулятор юнит-экономики

Локальное приложение для расчёта расходов и маржи по SKU на Яндекс Маркете.

## Что внутри

* **Обзор** — портфель SKU: цена, расходы, маржа, маржинальность, цена под целевую маржу, статус.
* **Калькулятор** — карточка товара: параметры, полная структура расходов, цена под цель, цены входа в акции.
* **Тарифы** — комиссии по категориям, логистика по объёму, последняя миля, эквайринг, хранение, возвраты, утилизация, штрафы, налоги.

Считает:

* маржу и маржинальность по текущей цене;
* цену под целевую маржинальность с учётом ДРР, лимитов последней мили и минимальной цены;
* маржу по ценам акций, максимальную допустимую скидку и цену входа под цель.

## Установка

Двойной клик по `МАРКЕТ_Установка.exe` — установка начинается автоматически, без вопросов и кнопок.
Через несколько секунд приложение запустится само.

* ставится для текущего пользователя, без прав администратора;
* папка: `%LOCALAPPDATA%\Programs\MarketCalc`;
* ярлыки создаются на рабочем столе и в меню «Пуск».

Удаление — «Параметры → Приложения → МАРКЕТ» или `MarketCalc.exe --uninstall`.
Данные и настройки лежат в `%LOCALAPPDATA%\MarketCalc` и при удалении приложения сохраняются.

## Данные

Кнопка **«Загрузить данные»** принимает книгу Excel (`.xlsx`) или CSV. Листы (названия распознаются):

| Лист | Обязательный | Содержимое |
|---|---|---|
| Товары | да | SKU: артикул, название, категория, схема, цена, себестоимость, объём, возвраты |
| Комиссии | нет | ставки по категориям и схемам |
| Логистика | нет | ступени объёма и стоимость |
| Прочие тарифы | нет | последняя миля, эквайринг, хранение, возвраты, штрафы |
| Акции | нет | скидки, фиксированные цены, ДРР на период |
| Настройки | нет | цель по марже, ДРР, налоги, округление |

Если загрузить только лист «Товары», тарифы останутся прежними, а акции сбросятся.
Кнопка **«Шаблон»** скачивает готовую книгу со всеми листами и примерами.

Обязательный минимум для загрузки: `наименование` и `цена`. Остальное — по возможности.

## Формулы

```
Комиссия        = цена × ставка категории
Логистика       = тариф по объёму упаковки
Последняя миля  = min(макс, max(мин, цена × ставка))
Эквайринг       = цена × ставка
Хранение        = тариф × объём × дни
Возвраты        = доля × (стоимость возврата + комиссия, если не возвращается)
Утилизация      = плата за единицу × доля возвратов
Штрафы          = цена × ставка
Доставка        = фикс на единицу
ДРР             = цена × ставка
Налог           = выручка × ставка (УСН «доходы»)
Себестоимость, упаковка, прочее — из данных
Маржа           = выручка − сумма расходов
Маржинальность  = маржа / выручка
```

Цена под цель ищется бисекцией по маржинальности (зависимость кусочная из-за лимитов
последней мили и налогов), затем округляется вверх и ограничивается минимальной ценой.

## API

Версия локальная: источник данных — загруженная таблица. Модель данных совпадает с полями
Partner API (комиссии, логистика, цены, акции), поэтому подключение API заменит загрузку
файла без изменения расчётов. Статус — на странице «Тарифы».

## Сборка из исходников

```bash
pip install openpyxl pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name MarketCalc ^
  --icon assets/icon.ico ^
  --add-data "app/web;web" --add-data "app/data;data" app/server.py

python -m PyInstaller --noconfirm --onefile --windowed --name MarketCalc_Setup ^
  --icon assets/icon.ico ^
  --add-data "dist/MarketCalc.exe;payload" ^
  --add-data "assets/icon.ico;assets" installer/setup.py
```

Разработка: `python app/server.py` (сервер на свободном порту, окно Chrome в режиме приложения).

## Структура

```
app/
  server.py        локальный HTTP-сервер и API
  dataio.py        хранение, шаблон Excel, экспорт отчёта
  parsing.py       разбор загруженных таблиц
  data/default_bundle.json  демо-данные
  web/             интерфейс (HTML, CSS, JS)
installer/setup.py установщик
assets/            иконки
tools/             сборка демо-данных и иконки
dist/              собранные exe
```

## Примечания

* exe не подписан: Windows SmartScreen может показать предупреждение — «Подробнее → Выполнить всё равно».
* Приложение работает офлайн, в интернет не обращается.
* Расчёт предварительный и не заменяет бухгалтерию: налоговые режимы упрощены, НДС учитывается через настройки.
