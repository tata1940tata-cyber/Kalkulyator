# Калькулятор юнит-экономики Яндекс Маркета — данные и методика

Пакет входных данных для калькулятора, который считает расходы по SKU и цены под целевую маржу.

## Состав

```
docs/data_model.md              описание модели, формулы, источники, допущения
data/settings.json              настройки: налоги, целевая маржа, ДРР, округление
data/tariffs.json               тарифы площадки (FBY / FBS), версионирование
data/skus.csv                   товары: характеристики, себестоимость, цены
data/promos.csv                 акции и цены входа
data/expected_results.csv       эталонные расчёты для приёмки
tools/reference_calc.py         референсная реализация расчёта
tools/build_export_template.py  сборка Excel-шаблона
Шаблон_выгрузки_данных.xlsx     те же данные в таблицах для ручного заполнения
```

## Что умеет расчёт

* маржа и маржинальность по текущей цене;
* цена под целевую маржинальность с учётом ДРР, налогов, лимитов последней мили и минимальной цены;
* маржа и маржинальность по ценам входа в акции, с флагами «убыток», «ниже минимальной цены», «ниже минимума маржи».

## Запуск

```bash
python tools/reference_calc.py          # пересчитать эталон -> data/expected_results.csv
python tools/build_export_template.py   # пересобрать Excel-шаблон
```

Зависимости: только стандартная библиотека Python. Для Excel-шаблона нужен `openpyxl`.

## Как расширять

* **Новый товар** — строка в `data/skus.csv` (или на листе «Товары»).
* **Новая акция** — строка в `data/promos.csv`.
* **Изменение тарифов** — новая версия `tariffs.json` с `valid_from`, старую не правим.
* **Новая схема (DBS)** — блок в `schemes` по образцу FBY/FBS.

## Источники

Карточки и цены — Partner API Маркета; тарифы — кабинет и договор; себестоимость и упаковка — учётная система. Приоритет при конфликте: ручное подтверждение → выгрузка → API.

Ставки в примерах демонстрационные: перед боевым расчётом заменить на актуальные из кабинета.
